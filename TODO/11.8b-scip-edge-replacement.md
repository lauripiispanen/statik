### 11.8b SCIP edges replace tree-sitter edges for enriched files (S)
**Complexity**: S
**Prerequisites**: 11.8
**Files**: `src/cli/graph_builder.rs`, `src/cli/commands.rs`, `src/cli/output.rs`

**The problem**: After 11.8, SCIP edges are additive — they supplement tree-sitter
edges. But for SCIP-enriched files, tree-sitter edges include false positives:
unused imports creating phantom dependency edges, wildcard imports resolving to
wrong files, and ambiguous same-name classes resolving incorrectly. The compiler
knows the real dependencies; tree-sitter is guessing.

**Evidence** (external evaluation on 7K-file Java project):
- Tree-sitter already gets 98%+ of Java imports right at file level
- SCIP added 190 new file-level edges tree-sitter missed
- But tree-sitter false positives (unused imports, wrong wildcard resolution)
  persist alongside precise SCIP edges, defeating the purpose of enrichment
- 5,323 unresolved imports unchanged after enrichment — many would disappear
  if tree-sitter edges were replaced rather than supplemented

**The fix**: For SCIP-enriched files, replace outgoing tree-sitter edges with
SCIP-derived edges. Non-enriched files (JS/TS, files outside build) keep
tree-sitter edges.

**Design decisions**:
1. Per-file replacement, not global — only files with SCIP data get replaced
2. Remove tree-sitter unresolved imports for enriched files too
3. Summary should report "X files SCIP-precise, Y tree-sitter-heuristic"

**Implementation**:

Tasks:
- [ ] In `build_file_graph()`, after setting `scip_enriched`, remove outgoing
  tree-sitter edges (and their reverse `imported_by` entries) for enriched files
- [ ] Remove unresolved imports for enriched files from `graph.unresolved`
- [ ] Then add SCIP edges as before (dedup still applies for safety)
- [ ] Add `scip_precise_files` and `tree_sitter_files` to summary output
- [ ] Show "Resolution: N files SCIP-precise, M tree-sitter-heuristic" in summary
- [ ] Test: enriched file loses tree-sitter edges, keeps only SCIP edges
- [ ] Test: non-enriched file keeps tree-sitter edges unchanged

**Acceptance**: After enriching a project with SCIP, enriched files show only
SCIP-derived edges in `deps` output. Tree-sitter false positives (unused imports,
wrong wildcard resolutions) no longer appear for enriched files. Summary shows
the SCIP-precise vs tree-sitter-heuristic breakdown.
